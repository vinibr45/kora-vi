# Gestão de Conhecimento Weber Sistemas

Esta pasta centraliza a gestão de conhecimento da WEBER Sistemas.

## Objetivo

Organizar conhecimento sobre produtos, módulos, serviços, processos, telas, regras fiscais, suporte, implantação, treinamento e comunicação técnica da WEBER.

## Estrutura Inicial

```text
Weber Tributário IMENDES/
```

Conhecimento sobre o serviço Weber Tributário, sua relação com a IMENDES e os impactos das informações fiscais no cadastro de produtos.

```text
.kora/
```

Camada local da KORA para orientar como usar este repositório de conhecimento.

## Como Trabalhar Aqui

1. Registrar primeiro o contexto real do sistema.
2. Guardar fontes brutas em pastas de fontes ou prints.
3. Separar explicação técnica de orientação para suporte/cliente.
4. Marcar como `precisa confirmar` tudo que ainda depender de validação.
5. Evitar dados reais de clientes, CNPJ, valores, credenciais ou informações fiscais privadas sem necessidade.

## Tipos De Conteúdo

- contexto de módulos e serviços;
- glossário de campos;
- layout de telas;
- regras de negócio;
- orientações para suporte;
- artigos de wiki;
- roteiros de vídeo;
- checklists;
- validações e dúvidas pendentes.
