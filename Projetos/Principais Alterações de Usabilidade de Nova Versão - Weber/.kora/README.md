# KORA Local - WEBER Sistemas

Esta pasta guarda a camada local da KORA para a gestao de conhecimento da WEBER Sistemas.

## Como Usar

Quando precisar atualizar a base de conhecimento da WEBER, comece por:

```text
.kora/binding.md
.kora/context/weber-knowledge-management-context.md
.kora/context/source-inventory.md
.kora/skills/create-weber-knowledge-article.md
.kora/skills/criar-demandas-weber.md
.kora/agents/weber-wiki-image-publisher.md
```

## Fontes Conectadas

Esta camada local usa duas pastas como fonte:

```text
C:\Kora\kora-vi\Projetos\Principais Alterações de Usabilidade de Nova Versão - Weber
C:\Kora\kora-vi\Projetos\Projeto Wiki entrada de notas Recebe Fácil
```

E usa esta pasta como casa principal dos conteúdos organizados:

```text
C:\Kora\kora-vi\Projetos\Gestão de Conhecimento Weber Sistemas
```

## Regra Principal

Conteudo especifico da WEBER fica nesta camada local.

Metodos reutilizaveis para outros projetos podem ser avaliados depois com `skills/classify-scope.md` antes de qualquer promocao para KORA Core.

## Fluxos Locais

- Criar ou revisar artigo da wiki de versao.
- Criar ou revisar material de treinamento do Recebe Facil.
- Transformar alteracoes tecnicas em orientacao para suporte.
- Planejar prints, GIFs e roteiros.
- Registrar Weber Patches por data de release.
- Separar conteudo interno de conteudo publicavel para cliente.
- Criar RAA, RAI e RN para atendimentos, testes internos e necessidades do ERP Weber.
- Publicar imagens de Wikis WEBER no GitHub publico e gerar links embedded para colar no HTML.

## Cuidados

Use base de treinamento, homologacao ou dados ficticios sempre que possivel.

Antes de publicar materiais, revisar exposicao de:

- dados reais de clientes;
- CNPJ;
- valores;
- fornecedores;
- informacoes fiscais privadas;
- credenciais;
- dados de producao.
