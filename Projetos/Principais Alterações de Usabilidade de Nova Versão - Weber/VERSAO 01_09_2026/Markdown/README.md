# Weber Patches

Pacote de trabalho para estruturar a demanda **Weber Patches**.

## Objetivo

Criar um formato padrao de comunicacao de releases da Weber inspirado em patch notes de jogos online, adaptado ao contexto atual em que a Weber nao utiliza versionamento formal e separa as entregas por **data de release**.

## Arquivos

```text
demanda-weber-patches.md
template-weber-patch.md
template-wiki-tecnica-com-imagens.md
```

## Uso

- Use `demanda-weber-patches.md` como texto base para registrar a demanda internamente.
- Use `template-weber-patch.md` para documentar cada release da Weber.
- Use `template-wiki-tecnica-com-imagens.md` para criar artigos de wiki que orientem tecnicos a explicar para clientes o que mudou na versao de producao.
- Como nao existe versao formal do sistema, a identificacao principal do patch deve ser a data de release.

## Limites

Este pacote nao define um novo processo oficial de versionamento da Weber.

Ele organiza a comunicacao das atualizacoes usando a realidade atual: releases identificadas por data.
