# 01 - Preparacao de Ambiente

Este diretorio organiza o primeiro tutorial da Wiki de Entrada de Notas Recebe Facil.

## Estrutura da etapa

```text
originais/
```

Guarda os arquivos recebidos sem alteracao.

```text
imagens/
```

Guarda prints extraidos ou recortados do material original, quando estiverem disponiveis como arquivos separados.

```text
imagens-extraidas-odt/
```

Guarda as imagens extraidas do arquivo ODT original, numeradas conforme a ordem do passo a passo.

```text
revisado/
```

Guarda a versao trabalhada do tutorial, com linguagem revisada e estrutura pronta para Wiki.

## Estrutura do pacote da Wiki

```text
../../Html/
```

Guarda a versao em HTML pronta para abertura no navegador ou adaptacao para a plataforma de Wiki.

```text
../../Imagens/
```

Guarda uma copia das imagens usadas no HTML final.

```text
../../Prompts/
```

Guarda prompts de apoio para revisao ou geracao do artigo com outra IA.

```text
../../Gifs/
../../Videos/
```

Pastas reservadas para demonstracoes animadas e gravacoes, quando existirem.

## Observacao

O PDF original deve ser usado como referencia visual. A versao revisada em Markdown indica onde cada imagem deve entrar e sugere uma legenda didatica para ela.
