# Boundaries

KORA depends on clear ownership boundaries.

## Knowledge Base

Stores reusable general knowledge. It does not store project-specific identity, decisions, or operating history.

## Project Context

Stores project-specific context. It does not store general theory.

## Memory

Stores operational learning. It does not store unfiltered transcripts or external theory.

## Context Layer

Selects and assembles context. It does not own the facts it selects.

## Orchestration

Coordinates execution. It should not become a hidden knowledge base or monolithic prompt.

## Agents

Pursue objectives inside defined boundaries. They do not own all knowledge or all procedures.

## Skills

Define reusable procedures. They reference knowledge instead of duplicating it.

## Tools

Execute external capabilities. They do not decide strategic intent.

## Evaluation

Assesses quality. It does not directly rewrite source-of-truth stores without policy.

## Experiments and Learning

Convert results into improvement proposals. They do not promote observations into stable knowledge without criteria.
