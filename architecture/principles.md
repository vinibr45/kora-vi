# Principles

KORA is guided by these principles:

1. Single Source of Truth
2. Separation of Concerns
3. Composability
4. Context Efficiency
5. Modularity
6. Model Independence
7. Tool Independence
8. Evidence-Based Knowledge
9. Organizational Memory
10. Continuous Improvement
11. YAGNI
12. Human Control
