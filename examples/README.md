# Examples

Esta pasta mostra como usar a KORA em tarefas realistas.

Os exemplos nao sao resultados finais obrigatorios. Eles servem como mapas de raciocinio para transformar pedidos naturais em workflows KORA.

## Exemplos Disponiveis

```text
installed-kora-project.md
```

## Como Usar

1. Encontre o exemplo mais parecido com a sua tarefa.
2. Copie o formato mental, nao necessariamente o texto.
3. Adapte o pedido ao projeto, cliente, contexto ou resultado desejado.
4. Deixe a KORA escolher as skills e arquivos certos.

## Regra Pratica

Se nenhum exemplo combinar, use:

```text
Classifica essa tarefa e me diz o melhor caminho na KORA: [sua tarefa]
```
