# Example: Capability Gap

## User Request

```text
Isso esta repetitivo demais. Toda semana eu peço quase a mesma analise.
```

## KORA Route

```text
skills/route-user-request.md
skills/detect-capability-gap.md
skills/review-capability-gaps.md
skills/create-capability-plan.md
```

## Expected Handling

1. Identify the repeated work.
2. Check whether an existing skill already covers it.
3. Decide whether the gap is knowledge, context, skill, tool, integration, automation, eval, or agent.
4. Recommend the smallest useful capability.
5. Defer automation until the process is stable.

## Realistic Follow-Up

```text
Cria primeiro uma skill simples para padronizar essa analise.
```
