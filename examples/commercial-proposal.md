# Example: Commercial Proposal

## User Request

```text
Cria uma proposta comercial para a Acme, oferecendo diagnostico de funil e plano de conteudo para 90 dias.
```

## KORA Route

```text
skills/route-user-request.md
skills/create-commercial-proposal.md
skills/classify-scope.md
```

## Expected Handling

1. Confirm the project or client context if it is not available.
2. Keep client-specific details in the project context or output.
3. Use reusable proposal structure from KORA Core.
4. Produce a clear proposal with scope, deliverables, timeline, assumptions, investment, and next step.
5. Record learning only if the proposal reveals a reusable pattern.

## Scope Decision

```text
Proposal structure -> KORA Core
Client details -> local project context or output
Final proposal -> output/ or project repository
```

## Realistic Follow-Up

```text
Agora transforma essa proposta em uma versao mais consultiva e menos tecnica.
```
