# Example: Core Vs Project

## User Request

```text
Essa regra de conteudo deveria ficar na KORA ou no projeto?
```

## KORA Route

```text
skills/route-user-request.md
skills/classify-scope.md
```

## Expected Handling

1. Understand the rule and where it came from.
2. Check whether it is reusable across projects.
3. Check whether it depends on a specific client, brand, audience, platform, stack, or offer.
4. Recommend the storage location.
5. Explain the boundary clearly.

## Scope Decision

```text
Reusable principle -> KORA Core knowledge or skill
Specific brand rule -> local .kora/context/
Temporary execution note -> output or task notes
```

## Realistic Follow-Up

```text
Entao cria o arquivo no lugar certo e aponta onde ele deve ser usado.
```
