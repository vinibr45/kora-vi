# Example: Instagram Analysis

## User Request

```text
Analisa o Instagram desse negocio e me diz o que melhorar no posicionamento e nos proximos posts.
```

## KORA Route

```text
skills/route-user-request.md
skills/classify-task.md
skills/assess-integration-need.md
skills/select-context.md
```

## Expected Handling

1. Identify whether the user provided screenshots, exported data, a public handle, or API access.
2. Decide whether analysis can be manual or needs the Instagram integration.
3. Select relevant marketing knowledge:

```text
knowledge/marketing/positioning/positioning-concept.md
knowledge/marketing/content/educational-content-framework.md
knowledge/marketing/branding/brand-voice-principles.md
knowledge/marketing/metrics/marketing-metrics-reading.md
```

4. Produce observations, opportunities, recommended content angles, and next actions.
5. Avoid storing account-specific findings in KORA Core.

## Scope Decision

```text
Instagram analysis method -> reusable knowledge or skill
Specific account findings -> local project .kora/ or output
API requirements -> integration/tool assessment
```

## Realistic Follow-Up

```text
Cria um calendario de 14 posts baseado nessa analise.
```
