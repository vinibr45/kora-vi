# Example: Loose Idea Capture

## User Request

```text
Tive uma ideia: usar IA para qualificar leads antes de montar a proposta.
```

## KORA Route

```text
skills/route-user-request.md
skills/capture-loose-idea.md
skills/classify-scope.md
skills/select-ai-use-case.md
```

## Expected Handling

1. Restate the idea.
2. Decide if it is a note, learning, experiment, skill, automation, or project context.
3. Check evidence and recurrence.
4. Recommend the smallest useful next step.
5. Avoid creating an automation before the workflow is stable.

## Realistic Follow-Up

```text
Transforma isso em um experimento simples para testar com os proximos 5 leads.
```
