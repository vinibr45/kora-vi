# Example: Record Learning

## User Request

```text
Registra esse aprendizado: leads frios respondem melhor quando a primeira mensagem nao tenta vender, so valida o problema.
```

## KORA Route

```text
skills/route-user-request.md
skills/record-learning.md
skills/review-learning.md
skills/promote-learning.md
```

## Expected Handling

1. Identify where the learning came from.
2. Decide whether it is local, global, or not yet proven.
3. Record the learning with source, context, confidence, and possible future use.
4. Review before promoting into knowledge, skill, decision, or memory.

## Scope Decision

```text
Observation from one client -> local memory
Pattern across many sales contexts -> reusable sales knowledge
Rule that changes a workflow -> skill update or decision record
```
