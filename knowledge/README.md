# Knowledge

This directory stores reusable general knowledge for KORA.

Knowledge should be modular, source-aware when needed, and reusable across different KORA implementations.

Do not place project-specific context here.

## Current Specification

```text
docs/knowledge/kora-knowledge-spec-v0.2.md
```

## Core Rule

```text
KORA knows the principle.
The project knows how the principle applies locally.
```

## Initial Domain

The first prioritized domain is:

```text
knowledge/marketing/
```

## Entry Format

Use Markdown. When metadata is useful, use YAML frontmatter.

Start from:

```text
knowledge/templates/knowledge-entry-template.md
```
