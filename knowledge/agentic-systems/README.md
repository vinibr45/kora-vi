# Agentic Systems

This directory stores reusable knowledge about agentic architecture for KORA.

It covers agents, subagents, custom agents, context engineering, skills, tools, orchestration, capability design, memory, evals, and structural decision-making.

Do not place project-specific agent instructions, private prompts, account credentials, or local repository facts here. Those belong in the project `.kora/` binding.

## Core Rule

```text
Agentic design is role, context, procedure, permission, execution, evaluation, and learning.
```
