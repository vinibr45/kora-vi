# Local KORA

This directory connects this project to KORA Core.

Start with:

```text
.kora/binding.md
```

## Local Owns

This project owns:

```text
project identity
project context
stack and implementation details
audience and offers
local decisions
local memory
project-specific skills, agents, tools, evals, experiments, and automations
```

## Uses From KORA Core

KORA Core provides reusable:

```text
architecture
skills
agents
knowledge
templates
tools and integration definitions
eval patterns
governance rules
```

## Daily Use

Useful requests:

```text
Vamos rodar o dia.
Tive uma ideia.
Isso esta repetitivo.
Vamos checar a saude.
Precisa de aprovacao?
```

## Boundary

Do not copy KORA Core into this project.

Do not store secrets, tokens, credentials, or sensitive payloads in `.kora/`.
