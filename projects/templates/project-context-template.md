# Project Context Template

Use this template for project-specific context files inside:

```text
<project-repository>/.kora/context/
```

## Purpose

What this context file explains.

## Current Truth

The current known truth for this project.

## Important Details

Relevant details that agents, skills, or workflows should know.

## What This Affects

Examples:

- content;
- offers;
- product;
- UX;
- sales;
- operations;
- implementation;
- support;
- automations.

## Boundaries

What this context does not define.

## Open Questions

Questions that should be clarified later.

## Related

Related context files, decisions, memory, knowledge, agents, skills, tools, or evals.
