# promote-learning

## Purpose

Decide whether an outcome should become memory, knowledge, a decision, or a capability improvement.

This skill helps KORA improve continuously without storing noise.

## When To Use

- After meaningful execution results.
- After experiments.
- After repeated user corrections.
- When a pattern appears across projects.
- When a local learning may become reusable global knowledge.
- When an agent, skill, tool, eval, or automation should be improved.

## Inputs

- Task result.
- User feedback.
- Eval result, if any.
- Project context.
- Existing memory.
- Existing knowledge.
- Existing decisions.
- Existing capabilities.

## Process

1. Identify what was learned.
2. Determine whether the learning is local, global, or not worth storing.
3. Determine whether it belongs in memory, knowledge, decision records, or capability updates.
4. Check whether evidence is strong enough for global knowledge.
5. Ask for approval when promotion affects source-of-truth stores.
6. Recommend the minimal useful update.

## Outputs

- Learning classification.
- Recommended destination.
- Proposed memory entry, knowledge entry, decision, or capability improvement.
- Evidence and limitation notes.
- Approval requirement, if applicable.

## Boundaries

This skill should not promote weak observations into global knowledge without evidence or human approval.

It should not store everything. Forgetting low-value noise is part of keeping KORA useful.
